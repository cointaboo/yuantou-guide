# Outlook / Hotmail 收不到验证码、提示账号已锁定怎么办 - 源头网

**一句话答案：**收不到码先别急着点重发：微软验证码可能发到备用邮箱、绑定手机或验证器应用，未必进账号本身的邮箱。若提示已向陌生地址发码，说明备用信息不在你手上，刷新也收不到；若提示账号已被锁定，需到 account.live.com 安全中心申请解锁。便宜成品号遇到这两种情况，换号常比死磕划算。

## 先弄清楚：验证码到底发到哪去了

微软账号（Outlook / Hotmail）在登录或改密时，验证码不一定发到账号本身的邮箱。系统可能把代码发到备用邮箱、绑定的手机号，或者推送给你之前设置过的验证器应用。很多时候页面还会先要求完成一步「验证是不是你本人登录」，这一步过了才会真正发码。所以在反复点重发之前，先确认一件事：验证码的目的地是不是你在用的那个收件箱。

最直接的线索就在提示文字里。如果页面写着已经向 a\*\*\*@x.com 发送了代码，或者已经向 138\*\*\*\*5678 发了短信，而这两个都不是你的，那收不到就是必然结果，在这台设备上怎么刷新都不会有码。这种情况下问题不在网络，也不在客户端，而在账号的备用信息不在你手上。

## 收不到验证码的五个常见原因

- 备用信息不是你的。成品号被卖出来的时候，卖家当初填的备用邮箱和手机号往往还留在账号里，验证码自然发到卖家那边。
- 账号已经被锁定。这种情况下系统根本不会给你发码，而是先把你挡在安全验证之外，只提示账号已被锁定。
- 转发规则或恢复方式被别人改过。有人可能在设置里加了自动转发或收件规则，把你要的邮件悄悄转到别处。这是最容易被忽略的后门。
- 登录 IP 与常用地区差别太大。上一个位置还在 A 地，这一次跳到 B 地，风控会直接把这次登录当成异常来处理。
- 用第三方客户端登录。走 IMAP / POP 的邮件客户端需要应用密码，用主密码反复试只会不断触发风控。

## 一张表看懂：现象、判断依据、该做什么

| 现象 | 判断依据 | 该做什么 | 
|---|---|---|
| 提示向 a\*\*\*@x.com 发送了代码 | 这个地址不是你的，备用信息在别人手上 | 不必反复刷新，先去安全中心尝试更换恢复方式；改不了就换号 | 
| 提示你的账号已被锁定 | 微软判定登录异常，已暂停访问 | 去 account.live.com 安全中心，用密保信息或手机号申请解锁 | 
| 一直回到验证页，始终没有发码 | 网络环境或浏览器缓存被风控盯上 | 先换成手机流量或住宅网络，再用官方网页版无痕窗口重试 | 
| 客户端提示密码错误 | 走的是 IMAP / POP，需要应用密码 | 开启双重验证后生成应用密码，用应用密码登录客户端 | 

## 提示账号被锁定，怎么走解锁流程

只要页面上明确写着账号已被锁定，就不要再在原地刷新了，发码是不会来的。正确的入口是 account.live.com 的安全中心，从那里提交解锁申请。系统会要求你回答当初设置的密保问题，或提交一个能收短信的手机号用于验证。

这里的关键在于，解锁需要用到账号的原始密保信息。如果这个号是买来的，密保问题、备用邮箱、绑定手机这些都不在你手上，那么解锁流程你多半走不通，因为这是账号所有权本身的问题，不是操作技巧能绕开的。遇到明确的锁定提示，可以先花几分钟试着走一遍安全中心，走不通就不要再投入时间。

## 成品邮箱到手后必做的三件事

无论这次有没有出问题，邮箱号一到手就应该先做加固，顺序如下：

- 第一件，改密码。用一个新的、和别处不重复的密码，改完立刻生效。
- 第二件，把恢复方式换成自己的。删除原卖家留下的备用邮箱和手机号，换成你能控制的地址或号码，这样以后验证码才会发到你手上。
- 第三件，检查转发规则和收件规则。进设置逐项看，凡是自己没添加过的转发、自动回复、收件分拣规则，一律删掉。这一步最容易被忽略，却恰恰是别人留后门的地方。

### 客户端登录要用应用密码

如果你打算用 Outlook 桌面端、手机端或者第三方邮件 App 收发信，建议先在账号里开启双重验证，然后生成一个应用密码，用这个应用密码去配置客户端。直接拿主密码在客户端里反复尝试，通常只会不断触发风控，把账号推到更麻烦的状态。

## 按顺序排查，不行就换号

- 第一步，确认验证码的去向。看提示里写的是发到备用邮箱、手机还是验证器，判断目的地是不是你能控制的。
- 第二步，换网络。切到手机流量或者住宅网络，避开被风控标记过的出口地址。
- 第三步，换官方网页版无痕登录。清掉缓存和旧会话，用无痕窗口重新试一次。
- 第四步，走解锁流程。若提示锁定，去安全中心用密保信息申请解锁。
- 第五步，仍然不行就换一个号。到了这一步通常说明账号的原始密保信息不在你手上，继续死磕的收益很低。

便宜成品号一旦碰到锁号，换号的成本往往比反复折腾更低。与其在一个已经不属于你的账号上耗时间，不如把精力放在下一个号上，并且第一时间改密、换恢复方式、清规则。把这三件事做成习惯，绝大多数后续麻烦都可以提前挡掉。

## 常见问题

### 收不到验证码，是不是网络的问题？

多数情况不是。先看提示里验证码发到了哪里：如果发到了 a\*\*\*@x.com 或者一个陌生手机号，说明备用信息不在你手上，换网络也没有用。只有当提示没说清目的地、或者你自己设置过收件箱时，才轮到检查网络和浏览器缓存。

### 提示账号已被锁定，付款能解开吗？

不能。锁定是微软侧的风控判定，需要用账号原始的密保信息或手机号在 account.live.com 安全中心申请解锁，没有付费绕过的通道。如果密保信息不在你手上，通常就只能换号。

### 成品邮箱号到手后最该先做什么？

第一件事是改密码，第二件是把恢复方式换成你自己能控制的邮箱或手机号，第三件是进设置检查有没有别人留下的转发规则和收件规则。这三件事做完，之后收验证码和账号安全才有保障。
